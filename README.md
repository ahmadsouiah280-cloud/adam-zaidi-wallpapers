# ADAM ZAIDI — Wallpaper Gallery

Responsive Arabic/English wallpaper gallery starter.

## Preview
Open `index.html` in a browser. Internet access is used for sample Unsplash photos and Google Fonts.

## Publish free using GitHub Pages
1. Sign in to GitHub and create a public repository named `adam-zaidi-wallpapers`.
2. Upload all files in this folder, preserving the `assets` folder.
3. Open repository Settings → Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site and show its URL.

## Features in this starter
- Responsive dark interface.
- Arabic and English toggle.
- Search and category filters.
- Favorites stored in the visitor's browser.
- Preview modal and links to larger images.

## Important
- Sample photos are remote Unsplash images. Replace them with images you own or are licensed to publish.
- This is a static starter version. It does not yet include user accounts, an admin upload dashboard, a server database, or a custom domain.
- The logo is an original ADAM ZAIDI mark, not an Amazon logo.
